# Topographic Dither Background Shader

Полный разбор и готовый исходный код для создания живого топографического фона в стиле ретро-киберпанка/дизеринга (как в лаунчере).

---

## 1. Как это работает (Математика и концепция)

Фон полностью генерируется в реальном времени на GPU через **WebGL Fragment Shader** (фрагментный шейдер). Он не использует картинки или текстуры — только математику и видеокарту (FPS 60-120+, минимальное потребление RAM и CPU).

### Ключевые компоненты шейдера:

1. **Координатная сетка и адаптивность (`uv`)**:
   - Пиксельные координаты экрана нормализуются в диапазон `[-1.0, 1.0]`, с корректировкой соотношения сторон (`aspect ratio`), чтобы круги и линии не сплющивались на экранах 16:9, 21:9 или 4:3.

2. **Искривление пространства без смещения камеры (Domain Warping)**:
   - Чтобы волны изгибались и «дышали» на месте (без улетания в сторону и без изменения масштаба/зума), координаты деформируются локальными синусоидами:
   ```glsl
   vec2 warped = p + vec2(
       sin(p.y * 1.5 + u_time * 0.18) * 0.35,
       cos(p.x * 1.2 + u_time * 0.14) * 0.30
   );
   ```

3. **Многослойный ландшафт высот (Harmonic Elevation)**:
   - Вместо одной плоской синусоиды складываются 4 гармоники разной частоты и направления:
   ```glsl
   float h = sin(warped.x * 2.2 + warped.y * 1.6 + u_time * 0.12) * 1.0
           + cos(warped.x * 3.4 - warped.y * 2.8 - u_time * 0.16) * 0.65
           + sin(warped.x * 5.0 + warped.y * 4.2 + u_time * 0.10) * 0.35
           + cos(warped.y * 6.5 + u_time * 0.08) * 0.20;
   ```

4. **Топографические изолинии уровней (Contour Lines)**:
   - Линии извлекаются функцией `fract()` (периодическое повторение по высоте):
   ```glsl
   // fract дает значения от 0 до 1 циклично
   float c = abs(fract(h * scale) - 0.5) * 2.0;
   // smoothstep отсекает тонкую четкую линию с мягким сглаживанием
   float line = 1.0 - smoothstep(0.0, lineWidth, c);
   ```
   В шейдере используются 3 градации линий:
   - `lineMajor`: редкие толстые яркие контурные линии
   - `line1`: средние стандартные изолинии
   - `lineMicro`: частая полупрозрачная микро-сетка на заднем плане

5. **Матрица упорядоченного дизеринга 8x8 (Bayer Ordered Dithering)**:
   - Вместо гладкого шума или резких полос используется классическая матрица Bayer 8x8:
   - Она циклично накладывается на экранные пиксели `(int(gl_FragCoord.x) % 8, int(gl_FragCoord.y) % 8)`.
   - Если интенсивность свечения выше порога матрицы — пиксель зажигается, иначе гаснет. Это создает неповторимый фирменный эффект ретро-мониторов и пиксельного рельефа.

6. **Мягкая виньетка и центр под контент**:
   - Центр экрана плавно затемняется радиальным градиентом, чтобы кнопки, карточки и логотип поверх фона читались идеально и не сливались с линиями.

## 2. Что внутри архива

- **`demo_topographic_dither.html`** — полностью автономная демо-страница (HTML + JS + WebGL в одном файле). Можно просто дважды кликнуть и открыть в Chrome/Firefox/Edge/Safari без сборщиков и серверов. В ней есть ползунки скорости, яркости, плотности линий и включение/выключение матрицы Bayer.
- **`DitherWaveCanvas.tsx`** — готовый компонент для React / Next.js / Vite / Electron. Достаточно импортировать `<DitherWaveCanvas />` и положить под ваш интерфейс (`position: absolute; inset: 0; z-index: 0`).
- **`README.md`** — данное руководство.

---

## 3. Как встроить в свой проект

### Вариант 1: Обычный HTML / Любой движок без фреймворков
Просто скопируйте `<canvas id="bg"></canvas>` и скрипт инициализации WebGL из `demo_topographic_dither.html`.

### Вариант 2: React / Next.js / Electron / Vue
Используйте `DitherWaveCanvas.tsx`. Шейдер слушает изменение размеров окна через `ResizeObserver`, автоматически оптимизирует рендеринг под `window.devicePixelRatio` и корректно освобождает память GPU при размонтировании.
