# Состояние проекта Eternal Launcher

## Стек и архитектура
- **Окружение**: Electron + Vite + React 19 + TypeScript + Tailwind CSS + Framer Motion.
- **Запуск**: Git Bash `./start` (скрипт запускает dev-сервер и нативное окно Electron).
- **Иконка приложения**: `assets/icon.ico` (привязана к процессу и панели задач Windows).

## Интерфейс и дизайн
- **Тема**: глубокий чёрно-серый монохром (`#070707`, `#0c0c0c`, `#161616`), без лишних ярких неоновых эффектов.
- **Title Bar**: кастомный (без системной рамки), поддержка перетаскивания окна, сворачивания, разворачивания (F11, кнопка, двойной клик) и закрытия (хитбокс прижат в правый верхний угол по закону Фиттса).
- **Слева (панель)**:
  - Логотип `E` в аккуратной рамке вверху.
  - Плоские кнопки с хитбоксом в стиле Prism Launcher (мягкая серая подсветка фона без свечения).
  - SVG-иконки: Play (главная), Instances (сборки), Mods (моды), Accounts (аккаунты).
  - Кнопка Settings в самом низу.
- **Settings**: отдельное модальное окно по центру (`#0c0c0c`, 960x640), закрывается по крестику / Escape / клику на фон. Пустое, без плейсхолдеров.
- **Главный экран (Play)**:
  - Логотип `E`.
  - Карточка сборки: имя, версия и кнопка «Версии».
  - Чекбокс: «Кастомный мод от лаунчера» (с подписью про текстовый логотип над никами).
  - Монохромная кнопка «Играть».
  - Быстрая каскадная анимация появления (staggered spring).

## Правила проекта
- `.agents/rules/no-unprompted-content.md`: запрет на выдуманные статусы, плейсхолдеры («Alpha Preview», «v1.0.0») и лишний текст.
