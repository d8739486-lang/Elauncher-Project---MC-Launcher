# Строгий чистый UI без шума

## 1. Запреты на текст и визуальный мусор
1. **Никаких смайликов и эмодзи** (ни в коде, ни в кнопках, ни в заголовках, ни в модалках).
2. **Никаких выдуманных статусов и меток**:
   - Запрещены: `// STATUS READY`, `ONLINE`, `TUNED & READY`, `ACTIVE`, `PRO`, `v1.0.0` (если версия не задана пользователем явно).
3. **Никаких лишних украшений**:
   - Никакого неонового свечения (glow), кислотных градиентов, фальшивых полос прогресса.
4. **Только функциональный текст**:
   - Кнопки содержат только действие: «Создать», «Удалить», «Отмена», «Выбрать».
   - Диалоговые окна подтверждения содержат только прямой вопрос и выбор.

## 2. Архитектура экранов управления (Instances)
1. Список сборок отображает только реальные данные: Название, Версия, Загрузчик (Fabric/Forge/Vanilla), Иконка.
2. Создание сборки:
   - Поле ввода названия.
   - Выбор версии Minecraft.
   - Выбор загрузчика модов (Fabric, Forge, NeoForge, Vanilla).
   - Выбор превью/иконки из доступных пресетов.
3. Удаление сборки:
   - Обязательное модальное окно второго подтверждения («Удалить сборку "..."? Действие необратимо.»).
   - Кнопки: «Отмена» и «Удалить».
4. Интеграция с воспроизведением клика `playPalateClick`.
